About the Project

Built with Node.js Core

This project demonstrates how a basic web server can be created using Node.js without relying on frameworks such as Express.

What does it demonstrate?

The server uses Node.js core modules including HTTP, File System, Events and Streams. It also demonstrates asynchronous operations and the Node.js event loop.

Why Node.js?

Node.js uses an event-driven, non-blocking architecture that allows it to handle multiple requests efficiently. This makes it well suited for network applications and real-time services.
